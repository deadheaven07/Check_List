## ✨ Key Features
- **Luminous Light Palette**: Soft warm cream canvas with ambient radial pastel blurs (lavender, soft rose, mint).
- **Effortless Task Flow**: Quick-add input bar with keyboard support (`Enter`), category tags (*Personal, Work, Creative, Health*), priority flags, and energy-level chips (*⚡ Quick Win, ☕ Steady, 🔥 Deep Flow*).
- **Tactile Audio Feedback**: Synthesized marimba chime and water-droplet pop using the Web Audio API (no external audio files required).
- **Particle Confetti**: Interactive canvas confetti explosion on task completion.
- **Mindful Focus Sanctuary**: Built-in 25-minute Pomodoro focus timer with synthesized ambient soundscapes (*🌧️ Soft Rain, 🌊 Gentle Stream, 🕊️ White Hum*).
- **Bento Progress Overview**: Animated SVG circular progress ring, momentum tracker, and daily intention quotes.
- **Local-First & Offline**: Instantly auto-saves tasks to `localStorage`. Pure HTML, CSS, and Vanilla JavaScript with zero external build tools.

## 🚀 Quick Start
Simply open `index.html` in any web browser, or run:
```bash
open index.html
```
